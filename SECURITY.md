# Security policy

## Supported versions

Only the latest release gets security fixes. While the action is in 0.x, that is the latest `v0.<minor>`.

## Reporting a vulnerability

Report it privately through GitHub: **Security → Report a vulnerability** on
[this repository](https://github.com/adepanges/dokploy-cli-action/security/advisories/new). Please do not open a
public issue.

Include what an attacker can do and how to reproduce it. A vulnerability in the bundled
[`@dokploy/cli`](https://www.npmjs.com/package/@dokploy/cli) or in Dokploy itself belongs to the
[Dokploy project](https://github.com/Dokploy/dokploy/security); report it here too if this action makes it
reachable.

You get an answer within 7 days. A confirmed issue is fixed in a new release and disclosed in a GitHub
security advisory once that release is out.
